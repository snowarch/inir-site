# Contributing

Thanks for helping with the site.

- **A mistake in the docs?** Fix it in [iNiR's `docs/`](https://github.com/snowarch/iNiR/tree/main/docs), not
  here. The copies in this repository are generated.
- **Design, layout, the landing page or the build?** Open a pull request here. It builds as a check; the
  maintainer reviews and merges.
- Keep the voice of the project: short sentences, the thing as it looks on screen, no marketing words, no em
  dashes, no emoji in text.
- Use real screenshots of iNiR, never mockups.
- Check the page at phone width before opening the pull request.
