iNiR

A desktop shell for Niri, built on Quickshell.

InstallDocumentation

Three families

Switch between them any time with Super Shift W.

Colours from your wallpaper

Change the wallpaper and the shell, GTK and Qt apps, terminals, Firefox, Discord and the login screen take its colours.

Install

Arch comes first. Fedora, Debian and Ubuntu have automated paths, and NixOS has an experimental flake. iNiR needs Qt 6.9 or newer.

git clone https://github.com/snowarch/inir.git
cd inir
./setup install
  • Arch
  • Fedora
  • Debian
  • Ubuntu
  • NixOS

Restart after the installer finishes, then pick Niri at the login screen. Installing in detail
