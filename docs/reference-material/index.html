  • Left scroll action: Brightness, Volume, Workspaces or None.

  • Group style: Pills or Seamless.
  • Hover trigger height (px): How thick the screen-edge zone is that reveals the hidden bar.

  • Push windows when shown: Reserve screen space when revealed instead of overlaying windows.

  • Display a background behind the bar

  • Vignette effect
