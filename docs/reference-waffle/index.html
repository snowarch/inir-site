Theming

Section titled “Theming”
  • Use Material colors: Apply Material color scheme instead of Windows 11 grey
  • Color strength: Controls how vivid wallpaper-derived accent colors are
  • Soften colors: Subtly soften theme colors for a more natural look
  • Auto light/dark from wallpaper: Pick the light or dark scheme from each wallpaper’s brightness so text stays readable
  • Vesktop/Discord theming: Generate Discord theme from wallpaper colors
  • Spotify theming: Generate and apply Spicetify theme from wallpaper colors
  • Spotify theme: Choose the Spicetify layout while keeping iNiR wallpaper colors
  • Steam theming: Apply Material You colors to Steam via Millennium Material-Theme
  • Pear Desktop (YouTube Music): Apply Material You colors to YouTube Music Desktop App
  • LiMusic: LiMusic follows your wallpaper colours, from the next time it opens
  • Claude Code: Adds iNiR themes to Claude Code’s theme list: two follow your wallpaper, two keep a fixed Monokai palette
  • Zed editor: Generate Zed editor theme from wallpaper colors
  • VSCode editors: Generate theme for VSCode and its forks from wallpaper colors
  • Chrome / Chromium: Apply wallpaper-derived colors to Chrome and Chromium browser
  • Firefox: Follows the wallpaper from its next launch; LibreWolf, Floorp, Waterfox and Zen too.
  • OpenCode: Apply wallpaper-derived theme to OpenCode AI editor
  • Neovim / LazyVim: Generate inir.nvim theme plugin for Neovim/LazyVim from wallpaper colors (writes to ~/.config/nvim/lua/plugins/neovim.lua)
  • Theme standalone Cava: Manage ~/.config/cava/config; internal visualizers always use the options below
  • Transparency: Enable transparent UI elements

Section titled “Cava Options”
  • Color source: Live palette for internal visualizers and standalone cava

  • Framerate: Target refresh rate
  • Stereo: Split visualizer into left/right channels
  • Wave opacity: Fill opacity for shared wave visualizers
  • Blocked visualizer apps: Comma-separated playback apps to exclude from visualizers. Empty keeps automatic active-player selection.
  • Reset to defaults: Restore all cava settings to defaults
