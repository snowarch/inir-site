The inir command

Your family

Everything you can type after inir, read from the command itself each time this site is built. inir help shows the same list, and inir <command> --help the details of one. Shell actions (inir <target> <function>) are on the IPC page.

Section titled “inir run”

Run the shell; inir run – CMD runs CMD with a live notification

Option What it does
--daemon In the background
--foreground In this terminal
--session As the session service starts it
-c <PATH>, --config <PATH> Shell directory to use

inir doctor

Section titled “inir doctor”

Check the install and fix what it can

Option What it does
--check Only check, change nothing
--json The report as JSON
--offline Do not fetch the repo’s remote
--only <STEPS> Just these steps (–only=5,8)
--perf Snapshot of graphics and media at runtime
--fix-abi Rebuild Quickshell against the installed Qt
--yes Rebuild without asking
-c <PATH>, --config <PATH> Shell directory to use

Section titled “inir theme”

Theming targets for other apps

inir theme What it does
list-targets List declared theming targets

inir look

Section titled “inir look”

Your whole look in one file: share it, apply one, go back

inir look What it does
export Write your look to FILE (stdout when piped or -)
--name <NAME>, --wallpaper <URL>
import Apply a look file or https link, with a snapshot first
--dry-run, --no-wallpaper
history Snapshots taken before each import or restore
--json
restore Go back to snapshot N of the history
--dry-run, --no-wallpaper

inir hub

Section titled “inir hub”

Community hub: widgets, themes, web apps

Option What it does
--json As JSON
inir hub What it does
list What the hub has
--installed, --updates, --kind <widget|theme|iris-theme|webapp|family|component|design>
search Search by text
info One item in detail
install Install items
update Update items, or all
remove Remove items
sync Fetch the catalogue
status Catalogue age and source
--max-age <SECONDS>, --cached
sources Where the catalogue comes from
open Open the hub page, or one item
refresh Tell the shell to read the hub again
changed Tell the shell a kind changed
validate Check a hub repo’s items
bumps Changed items raise their version
new Start an item from a template
build Build a hub repo’s catalogue
preview Frame a widget’s preview

inir hook

Section titled “inir hook”

Live notifications for long commands in your shell

inir hook What it does
bash eval “$(inir hook bash)” in ~/.bashrc
--after <SECONDS>
zsh eval “$(inir hook zsh)” in ~/.zshrc
--after <SECONDS>
fish inir hook fish | source in config.fish
--after <SECONDS>

Option What it does
--yes Take each question’s default answer
--quiet Print less
--skip-deps Leave system packages alone
--skip-setups Skip services and permissions
--skip-files Skip copying config files
--skip-quickshell Skip syncing the shell files
--skip-niri Skip the Niri config
--skip-backup No snapshot before installing

--no-toolkit Without ydotool and backlight tools
--no-screencapture Without screenshots and recording
--no-fonts Without fonts and themes
--set-default-shell Make fish the default shell
--firstrun Act as a first run, backing up configs
--reset-dolphin-layout Reset Dolphin’s panel layout
